# blade
The darksword tool on iOS
17.0.1～18.7.2，26.0～26.0.1（iOS 26 Experimental）
This version is the first official release of Blade. I made many beta versions before this one, and this is the most polished version yet.
Features:
1. Application decryption
2. File management
3. Process management (list/terminate/modify memory of selected processes)
4. Install using certificate signing, altstore/sidestore/All-in-One Signing/Easy Signing
5. The experimental JIT feature doesn't seem to be working
